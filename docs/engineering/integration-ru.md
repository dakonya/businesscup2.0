## Ограничения

Интеграция проверена в режиме **rules**. Реальный inference NVIDIA в этой задаче не проверялся; отдельный UI fixture подтверждает только отображение `source=nvidia`. Ранее найденные смысловые ошибки маленькой NVIDIA-модели остаются отдельной задачей, поэтому rules — режим по умолчанию. Для явного включения модели нужен серверный `INCIDENTLAB_COACH_MODE=nvidia`.

Публичный deployment этим merge не создаётся; production URL не заявляется. Предыдущий блокер Vercel HTTP 403 описан в [operations](operations.md). Проверка headless-браузером и снимки мобильной ширины не заменяют тест на физическом мобильном устройстве или проекторе.

Перед публикацией интеграционной ветки GitHub API сообщил: `main.protected=false`, required status contexts/checks пусты, активные rules для main отсутствуют. Обязательных удалённых проверок на этот момент не настроено. PR следует объединять обычным merge после успешных локальных и браузерных проверок, без обхода ограничений репозитория.
