## Реальные запросы NVIDIA

Обе переменные `NVIDIA_API_KEY` и `NVIDIA_MODEL` присутствуют. Проверка загрузки окружения подтвердила, что эффективный ключ берётся из существующего `.env`; перекрывающего значения процесса или другого env-файла нет. Лишнего `Bearer`, пробелов и внешних кавычек не обнаружено. Значения ключа и модели не выводились, `.env` не изменялся и не добавлялся в Git.

В исходном package.json не было команды `npm run smoke`. Добавлен полноценный smoke через настоящий HTTP `/api/coach`: seed 42, горизонт 120000 ms, A = 4 API-реплики и B = 1 максимальная попытка на 20000 ms. Скрипт использует production-сборку и временный локальный сервер, который завершает после проверки. Для опубликованного приложения предусмотрен `INCIDENTLAB_SMOKE_URL`.

Сделано **два реальных POST** к NVIDIA: первый полный smoke и один диагностический запрос, необходимый из-за прежнего слишком общего предупреждения. Ответ NVIDIA: **HTTP 401**, безопасная диагностическая строка: `Invalid JWT serialization: Missing dot delimiter(s)`. Приложение честно вернуло HTTP 200 с `source: rules`; smoke завершился кодом 1 и не засчитал это как inference.

Это подтверждённый отказ авторизации до генерации ответа модели. Доступность выбранной модели после авторизации, корректность её выходного текста и фактические evidence IDs NVIDIA-ответа пока проверить нельзя. Таймаут, усечение и ошибка Zod не установлены как причина текущего отказа. Повторять запросы с тем же credential без изменения причины прекращено; другой провайдер не подключался.

Исправлена различимость безопасных предупреждений: HTTP 401 обозначает ошибку аутентификации, 403 — отказ доступа, 429 — лимит провайдера. Upstream body, значения env и внутренние ошибки не выдаются клиенту. Существенная валидация, лимиты и rules fallback сохранены.

## Demo-run

Seed **42**, горизонт **120000 ms**, вмешательства на **20000 ms**. Каждая ветка получает **960** уникальных клиентов.

| Метрика | A: API replicas = 4 | B: max attempts = 1 |
| --- | ---: | ---: |
| Succeeded | 120 | 709 |
| Failed | 800 | 248 |
| Pending | 40 | 3 |
| Попытки БД | 2588 | 987 |
| Повторы | 1632 | 27 |
| Конечная очередь БД | 1355 | 0 |
| p95 успешных ответов, ms | 394 | 397 |

B − A: **+589** успехов, **−552** провала, **−1601** попытка БД. Нельзя скрывать оставшиеся 248 провалов и 3 pending у B. p95 относится только к успешным запросам и не заменяет failed/pending. Это результаты учебной модели, а не универсальная production-рекомендация и не оценка профессиональной готовности.

Последняя локальная пара replay заняла **66,07 ms** в Node без сериализации; это не browser performance guarantee. Trace: 12130 / 5466 событий, JSON: около 2,56 / 1,11 млн символов. Полные trace нельзя хранить в localStorage или перерисовывать на каждом кадре.
